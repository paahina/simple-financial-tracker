SIMPLE FINANCIAL TRACKER
REST API Specification - MVP
============================

BASE URL

/api

Authentication:
- Protected endpoints require an authenticated user.
- Exact authentication implementation is defined in the tech stack.

--------------------------------------------------
USER
--------------------------------------------------

POST /api/users/register
Create a user.

POST /api/users/login
Authenticate a user. Returns a Bearer token.

POST /api/users/logout
End authenticated session. Requires Authorization: Bearer token.

GET /api/users/session
Return current authenticated user.

GET /api/users/getAllUsers
List users. Requires SYSTEM_ADMIN.

GET /api/users/get/:id
Get one user. Owner or SYSTEM_ADMIN.

PUT /api/users/update/:id
Update one user. Owner or SYSTEM_ADMIN.

DELETE /api/users/delete/:id
Delete one user. Requires SYSTEM_ADMIN.

Amounts are integer centavos. PHP 100.50 is 10050.
All routes below require Authorization: Bearer token.
A user can only access their own financial records.

--------------------------------------------------
ACCOUNTS
--------------------------------------------------

GET /api/accounts/getAllAccounts
List current user's accounts, each with a derived balance.

POST /api/accounts/create
Create an account. Fields: name, type (CASH, E_WALLET, BANK), initialBalance, currency, description.

GET /api/accounts/get/:id
Get one account and its balance.

PUT /api/accounts/update/:id
Update name, type, currency, or description. Initial balance cannot change.

DELETE /api/accounts/delete/:id
Deactivate the account.

GET /api/accounts/get/:id/activity
Transactions, transfers, and debt payments for the account.

--------------------------------------------------
CATEGORIES
--------------------------------------------------

GET /api/categories/getAllCategories
List categories. Default income and expense categories are created on first use.
Optional query: type=INCOME or type=EXPENSE.

POST /api/categories/create
Create a category. Fields: name, type.

PUT /api/categories/update/:id
Update name or isActive.

DELETE /api/categories/delete/:id
Deactivate the category.

--------------------------------------------------
TRANSACTIONS
--------------------------------------------------

GET /api/transactions/getAllTransactions
List income and expenses.

Supported filters:
- type
- accountId
- categoryId
- startDate
- endDate
- search
- page
- limit

POST /api/transactions/create
Create income or expense.
Fields: accountId, type (INCOME or EXPENSE), amount, label, categoryId, description, transactionDate.

GET /api/transactions/get/:id
Get one transaction.

PUT /api/transactions/update/:id
Update a transaction.

DELETE /api/transactions/delete/:id
Delete a transaction.

--------------------------------------------------
TRANSFERS
--------------------------------------------------

GET /api/transfers/getAllTransfers
List transfers.

POST /api/transfers/create
Move money between two accounts owned by the user.
Fields: fromAccountId, toAccountId, amount, description, transactionDate.
A transfer is not income or expense.

GET /api/transfers/get/:id
Get one transfer.

PUT /api/transfers/update/:id
Update a transfer.

DELETE /api/transfers/delete/:id
Delete a transfer.

--------------------------------------------------
DEBTS
--------------------------------------------------

GET /api/debts/getAllDebts
List debts with derived remainingAmount and status.

POST /api/debts/create
Create a receivable. Fields: personName, description, originalAmount, dueDate.

GET /api/debts/get/:id
Get one debt and its payments.

PUT /api/debts/update/:id
Update a debt.

DELETE /api/debts/delete/:id
Delete a debt that has no payments.

GET /api/debts/getPayments/:id
List payments for a debt.

POST /api/debts/createPayment
Record a payment. Fields: debtId, accountId, amount, paymentDate, notes.
The payment increases the selected account and cannot exceed the remaining debt.

PUT /api/debts/updatePayment/:id
Edit a payment.

DELETE /api/debts/deletePayment/:id
Delete a payment.

--------------------------------------------------
DASHBOARD
--------------------------------------------------

GET /api/dashboard/get
Return the current month summary:
- totalMoney
- monthlyIncome
- monthlyExpenses
- monthlyNet
- outstandingReceivables
- accountBalances
- recentTransactions

--------------------------------------------------
REPORTS
--------------------------------------------------

GET /api/reports/monthly?year=2026&month=10

Return:
- income
- expenses
- net
- incomeByCategory
- expensesByCategory

Transfers and debt payments are excluded from income and expenses.

GET /api/reports/yearly?year=2026

Return:
- income
- expenses
- net
- monthlyBreakdown

--------------------------------------------------
API RESPONSE CONVENTION
--------------------------------------------------

Success example:

{
  "success": true,
  "data": {}
}

Error example:

{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Amount must be greater than zero"
  }
}

Pagination example:

{
  "success": true,
  "data": [],
  "pagination": {
    "page": 1,
    "limit": 20,
    "total": 100,
    "totalPages": 5
  }
}

HTTP STATUS GUIDELINES

201 Created
204 No Content
400 Bad Request
401 Unauthorized
403 Forbidden
404 Not Found
409 Conflict
422 Unprocessable Entity when appropriate
500 Internal Server Error
