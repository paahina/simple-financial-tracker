SIMPLE FINANCIAL TRACKER
Feature Specification
=====================

FEATURE PRIORITY

P0 = Required for MVP
P1 = Useful after MVP
P2 = Future / optional

--------------------------------------------------
1. AUTHENTICATION & AUTHORIZATION
--------------------------------------------------

P0 Register
- User provides name, email, password.
- Password must be securely hashed.
- Email must be unique.

P0 Login
- Authenticate user.
- Establish authenticated session.

P0 Logout
- Invalidate the user's authenticated session/token.

P0 User roles
- SYSTEM_ADMIN
- USER

P0 Authorization
- USER can access only their own financial data.
- Admin endpoints must be explicitly protected.

P1 Profile management
- Change display name.
- Change password.

--------------------------------------------------
2. ACCOUNTS
--------------------------------------------------

Accounts are the user's manually created sources/stores of money.

Examples:
- GCash
- Maya
- BPI Savings
- BDO
- Cash

P0 Create account
Fields:
- name
- type
- initialBalance
- currency
- optional description

P0 Account types
- CASH
- E_WALLET
- BANK

P0 View accounts
- List active accounts.
- Show current balance.

P0 Edit account
- Change name/type/description according to business rules.

P0 Deactivate account
- Prefer deactivation over destructive deletion when the account has financial history.

P0 Account balance
Current balance is derived from:
initial balance
+ income
- expenses
+ transfers in
- transfers out

P1 Account transaction history
- View all activity affecting an account.

P1 Pagination

--------------------------------------------------
4. TRANSFERS
--------------------------------------------------

Transfers are separate from normal transactions.

Reason:
A transfer does not represent income or expense. It only moves existing money between accounts.

P0 Create transfer
Fields:
- fromAccountId
- toAccountId
- amount
- description
- transactionDate

Rules:
- Source and destination must be different accounts.
- Both accounts must belong to the authenticated user.
- Amount must be positive.
- Transfer must affect both account balances.
- Transfer must not count as income or expense.

P0 Edit transfer

P0 Delete/cancel transfer

P1 Transfer history
